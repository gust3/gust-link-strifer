# ✂️ Gust Link Strifer

**Gust Link Strifer** — это удобное и легковесное расширение для браузера, которое помогает навести порядок в ссылках. Зачёркивайте прочитанные статьи, просмотренные видео или изученные страницы разными цветами, чтобы больше не открывать их повторно.

Расширение доступно для **Firefox** и **Opera**, а также совместимо с другими браузерами на базе Chromium (Chrome, Yandex, Edge) через режим разработчика.

---

## 🚀 Основные возможности

*   🎨 **Разные цвета:** Выбирайте из палитры готовых цветов или создавайте свои собственные для категоризации ссылок.
*   ⚡ **Быстрое зачёркивание:** Зажмите `Alt` и кликните по ссылке, чтобы зачеркнуть её мгновенно. `Alt+Shift+Click` открывает мини-палитру прямо у ссылки.
*   📊 **Умный счётчик:** Перетаскиваемый виджет показывает, сколько ссылок вы зачеркнули на текущей странице и всего.
*   🧹 **Легкая очистка:** Убирайте зачеркивания со всей страницы или со всего домена в один клик.
*   💾 **Экспорт/Импорт:** Все данные хранятся локально. Вы можете сделать резервную копию или перенести их на другое устройство.
*   🌍 **Локализация:** Полная поддержка русского и английского языков.

## 📦 Структура репозитория

В репозитории представлены готовые сборки для разных платформ:

*   📁 `/firefox/` — Исходный код и сборка, адаптированная для Firefox (Manifest V3 с поддержкой `browser_specific_settings`).
*   📁 `/opera/` — Исходный код и сборка для Opera и других Chromium-браузеров.
*   📁 `/zips/` — Готовые `.zip` архивы для ручной установки или загрузки в магазины расширений.

## 🛠 Установка

### 🦊 Firefox
Самый простой способ — установить расширение из официального магазина:
👉 **[Установить из Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/gust-link-strifer/)** *(Замени ссылку, когда она появится)*

### 🎭 Opera
Публикация в магазине Opera ожидается в ближайшее время. Пока вы можете установить версию из папки `/opera/` в режиме разработчика.

### 🌐 Chrome / Yandex / Opera (Ручная установка)
Если вы хотите установить расширение вручную (например, из ZIP-архива):
1. Скачайте и распакуйте ZIP-архив из папки `/zips/` (или скачайте исходники).
2. Откройте браузер и перейдите на страницу управления расширениями:
   * Opera: `opera://extensions/`
   * Chrome: `chrome://extensions/`
   * Yandex: `browser://extensions/`
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку с распакованным расширением.
6. Готово! Закрепите иконку на панели браузера.
